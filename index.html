¿QUÉ ES DMR TONE GEN?

Generador de tonos de despacho compatible con el estándar Motorola Quick Call II (QC2) y las alertas nativas Zetron (Model 15P/25/284). Diseñado para sistemas de radio DMR Motorola MOTOTRBO.

CÓMO GENERAR UN TONO

  1. Selecciona una plantilla desde el dropdown de la izquierda, o crea tu propia secuencia desde cero con + ADD BURST.
  2. Cada burst es un tono individual dentro de la secuencia. Configura frecuencia, duración, tipo de onda, fade in y fade out.
  3. Presiona PLAY para previsualizar el tono en tiempo real con el visualizador de onda.
  4. Si suena bien, presiona EXPORT WAV para descargar el archivo listo para tu consola de despacho.

SINTAXIS DEL CAMPO FRECUENCIA

1000 Tono puro a 1000 Hz
800→1500 Sweep: barrido lineal de 800 Hz a 1500 Hz durante la duración del burst. Úsalo para sirenas. Escribe 800->1500 o usa el botón ⟶ SWEEP.
1000, 1500 Polyphony: reproduce 1000 Hz y 1500 Hz simultáneamente (el volumen se reparte). Separa con coma o usa el botón + POLY.
0 Silencio. Útil para pausas entre beeps.

CONSEJOS IMPORTANTES

  • Usa siempre tipo de onda Sine para sonar idéntico al estándar Zetron. Triangle y Square agregan armónicos que distorsionan el tono en el codec.
  • El Fade In y Fade Out evitan clics audibles al inicio y final de cada burst. Valores recomendados: 10 ms para tonos largos, 8 ms para beeps cortos.
  • Todas las frecuencias deben estar entre 553 y 1600 Hz para pasar correctamente por el codec AMBE+2 del DMR. Valores fuera de rango se recortarán automáticamente.
  • El WAV se exporta a 44100 Hz, 16-bit mono, compatible con consolas de despacho y equipos de radio profesionales.

LIBRERÍA LOCAL

Guarda tus tonos personalizados con un nombre usando GUARDAR EN LIBRERÍA. Los datos se almacenan en el navegador (localStorage). Usa EXPORT JSON para hacer respaldo o compartir con otros operadores, e IMPORT JSON para restaurarlos.
